# Forest plates v3

Plates-only forest packing, fixing v2's layout problems:

- far names (~950 of the 1000) are a soft, terrain-tinted texture on the distant foothills/field,
  feathered with vertical + horizontal gradient masks and organic noise density (no rectangular blocks)
- no clearing under the jar: the canister is simply layered above; the far texture continues behind the glass
- readable plates use best-candidate placement with collision avoidance against each other, oak canopies,
  trunks and root flares, the jar footprint, the hero copy and the visible stage edges (incl. Safari's bottom bar)
- the three main plates (جماران / باهنر کرمان / الزهرا اصفهان) are placed beside their foreground oaks, clear of the jar,
  same plate style (weight 600), slightly larger
- plate canvas lives inside #zhSpots below the oaks, so trees occlude plates behind them
